# 青茉日记

青茉日记是一款仅在本机使用、默认不带任何作品数据的 Android 随笔应用。

## 功能

- **随笔**：标题、心情、正文、照片、搜索、编辑与删除。
- **影视**：空白片单，可手动添加电影、剧集、动画或纪录片，并上传本地海报。
- **动漫**：空白片单，可记录在看、想看、看过状态、年份、总集数、观看时间和一句简评。
- **时间线**：合并随笔、影视和动漫活动，并统计随笔、片单和本月记录。
- **主题**：全局深色与浅色模式。
- **备份**：影视和动漫记录可分别导出、导入 JSON 备份。

## 版本

- 应用名：青茉日记
- 版本：1.0
- 包名：`com.local.qingmo`
- 最低系统：Android 7.0
- 目标系统：Android 14（兼容 Android 15 / HyperOS）

该包与“朝花夕拾”使用不同包名，可以同时安装，不会覆盖原有数据。

## 数据与隐私

- 不申请网络、定位、通讯录或全盘存储权限。
- 随笔文字保存在应用私有 SQLite 数据库。
- 随笔图片压缩后保存在应用私有目录。
- 影视、动漫、观看时间和简评保存在 WebView 的本地存储。
- 不启用 Android 云备份，不连接外部服务器。
- 卸载应用或清除应用数据会删除本地内容，重要记录请定期导出备份。

## 构建

准备 JDK 17、Android SDK Platform 35 和 Build Tools 35.0.0，然后设置：

```bat
set JAVA_HOME=C:\path\to\jdk-17
set ANDROID_SDK_ROOT=C:\path\to\android-sdk
build.bat
```

生成的安装包位于 `dist/QingMoDiary-v1.0.apk`。

## 安装

从 GitHub Releases 下载 `QingMoDiary-v1.0.apk`，在手机上允许“安装未知应用”后安装即可。
